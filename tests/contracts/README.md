# 契约测试夹具

本目录保留设计阶段用于验证 JSON Schema 正反例的合成请求、临床 JSON 和报告。它们只供 tools/validate-design.py 使用，不是可执行业务输入，也不是转换/签署的验收证据，不进入二进制发行包。

临床文字、标识、代码和报告结果均为测试值。实际接入应使用自己的导出文件、来源版本及本地临床规范，参见 [接入说明](../../docs/integration.md)。当前生产代码不加载这些文件，也不内置相应临床 Schema。

请求和报告契约位于 [contracts](../../contracts)。运行时格式、密码运算与进程测试位于三个 Maven 模块的 src/test 下；这些测试生成实际文件及临时密钥，并检查结果和失败路径。
